# Сборка и тестирование

## Сборочная инфраструктура

`Package.swift` описывает библиотеку `MacSpaceCore`, исполняемый модуль `MacSpace` и два тестовых модуля. Минимальная система — macOS 14, язык Swift 6. Для разработки откройте пакет в Xcode или используйте SwiftPM из терминала.

```sh
swift test
./scripts/build-app.sh
open .build/MacSpace.app
```

`scripts/swift-local.sh` запускает `build` или `test` с кэшами в `.build`, чтобы работать и в средах с запретом записи в пользовательские кэши. Он отключает sandbox самого SwiftPM; пакет не содержит сторонних зависимостей, плагинов или генераторов сборки. Например: `./scripts/swift-local.sh test --filter DiskScannerTests`.

`scripts/build-app.sh [debug|release]` собирает текущую архитектуру, копирует бинарный файл и `Resources/Info.plist` в `.build/MacSpace.app`, генерирует Retina-иконку из `scripts/make-icon.swift`, упаковывает её через `iconutil` и применяет локальную ad-hoc подпись. Бинарник подменяется через временный файл и `mv`, чтобы не перезаписывать исполняемый файл работающего экземпляра; для загрузки изменений приложение нужно перезапустить. Проверка подписи включена в скрипт. Приложение не использует App Sandbox: доступ к пользовательским и системным папкам регулируют права файловой системы и macOS TCC. Публикация, сертификат Developer ID, notarization и universal-сборка не входят в этот скрипт.

## Автоматические проверки

```sh
./scripts/swift-local.sh test
./scripts/build-app.sh
```

Наборы тестов:

| Набор | Что проверяет |
| --- | --- |
| `DiskScannerTests` | Реальные временные каталоги, агрегирование, связи дерева, ссылки, sparse, FIFO, доступ и отмена |
| `TreemapLayoutTests` | Пропорции площадей, непересечение, границы и некорректный вход |
| `TrashServiceTests` | Ограничение путей, ссылки, подмена inode без фактического переноса |
| `AppModelTests` | Сквозные переходы состояния интерфейса со сканированием реальных временных каталогов |
| `SnapshotRemovalTests` | Вычитание из снимка, жёсткие ссылки, отчёт об ошибках и повторные пути |
| `TrashUpdateTests` | Успех/ошибка переноса, навигация и отсутствие повторного сканирования |
| `FolderExpansionTests` | Разворачивание строк, вложенность, сортировка, фильтр и сохранение состояния |
| `WorkspaceFeatureTests` | Мультивыбор, файлы, частичный отказ, вкладки, подтверждение очистки и кэши |
| `TrashDirectoryTests` | Очистка только тестовых корней, защита внешних путей, ссылок и подмены inode |
| `RenderingTests` | Нативная отрисовка начального экрана и трёх представлений в светлом/тёмном оформлении |
| `TimeMachineServiceTests` | Даты, точные команды через подменённый исполнитель, ошибки, авторизация, экранирование, тайм-аут и отмена |
| `TimeMachineModelTests` | Подтверждение/отмена, мультивыбор, частичный отказ, устаревшее чтение, сохранение рабочих областей |

Тест недоступной папки использует `chmod` и рассчитан на запуск обычным пользователем, не root. Все временные деревья создаются с UUID и удаляются после проверки. Реальная пользовательская Корзина и снимки Time Machine в автотестах не изменяются; удаление снимков и системная авторизация подменены.

Для сохранения снимков основной области интерфейса:

```sh
MACSPACE_CAPTURE_PREVIEWS=1 ./scripts/swift-local.sh test --filter RenderingTests
```

PNG сохраняются в `.build/previews/`. Тест использует собственное скрытое окно `NSHostingView` и требует графическую сессию macOS. Системная панель инструментов и инспектор SwiftUI Scene проверяются в запущенном `.app`, а не по этим снимкам.

## Проверка интерфейса

На отдельном тестовом дереве проверьте:

1. Начальный экран, выбор папки, прогресс, отмену и повторный запуск.
2. Согласованность размеров между шкалами, картой и таблицей для обеих метрик.
3. Сортировку крупные/небольшие/по имени, заголовки таблицы и фильтр без учёта регистра.
4. Двойной щелчок, крошки, переход вверх, `⌘↑` и `⌘↓`.
5. Раскрытие карты кликом и сворачивание по шапке, размер справа при длинном имени, неизменность геометрии при выделении.
6. Сведения, скрытие инспектора, Finder и отчёт о недоступных путях.
7. Отмену диалога переноса, затем перенос только специально созданной папки и восстановление в Finder; запрет команды для корня.
8. Светлое/тёмное оформление и изменение размеров окна.
9. Нажатие именно стрелки справа: раскрытие/сворачивание без перехода в папку; несколько уровней, сортировка детей и удаление раскрытой папки.
10. Мультивыбор через Command/Shift, пакетный перенос файлов и папок, частичный отказ. Очистку проверяйте только на тестовом каталоге через внедрённую тестовую службу; реальную Корзину пользователя автотесты не очищают.
11. Time Machine: список дат, мультивыбор, пустое состояние/отказ доступа, отмена подтверждения, сохранение анализа при переключении. Реальное удаление допускается только по отдельной явной команде владельца данных, не как этап разработки. Подробности: [time-machine.md](time-machine.md).

Проверки состояния не заменяют проверку системных диалогов прав доступа и фактической работы Корзины на конкретном томе.

Отдельная интеграционная проверка системного API Корзины запускается явно:

```sh
swift scripts/trash-smoke.swift "$PWD/.build"
```

Она создаёт UUID-каталог только с тестовыми данными, перемещает его в Корзину, возвращает, проверяет содержимое и удаляет собственные временные данные. В обычный `swift test` эта операция не входит. Результаты текущей проверки: [verification.md](verification.md).
