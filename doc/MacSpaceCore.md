# Модуль MacSpaceCore: модель данных

## Назначение и использование

Библиотека `Sources/MacSpaceCore` не зависит от SwiftUI и предоставляет снимок дискового дерева, сканирование, геометрию карты, перенос и очистку Корзины, управление локальными снимками Time Machine. Подключается как продукт Swift Package Manager. Точки входа: `DiskScanner.scan`, `TreemapLayout.tiles`, `TrashService.moveToTrash`, `TrashDirectoryService.locations/empty`, `TimeMachineService.list/delete`.

```swift
let snapshot = try await DiskScanner().scan(root: folderURL)
let children = snapshot.children(of: snapshot.rootID, metric: .allocated)
```

Подробная эксплуатация приложения: [usage.md](usage.md). Технические описания служб: [scanning.md](scanning.md), [visualization.md](visualization.md), [trash.md](trash.md).

## Устройство

`DiskModel.swift` содержит неизменяемые для потребителя `Sendable`-снимки:

| Тип | Содержимое |
| --- | --- |
| `DiskNode` | URL, идентификатор родителя, тип, inode и устройство, ID детей, логический и выделенный размер, число потомков, ошибка чтения и путь первоначального учёта |
| `ScanSnapshot` | Словарь узлов по абсолютному пути, ID корня, ограниченный список ошибок с полным счётчиком, время и длительность обхода, ёмкость тома |
| `SizeMetric` | `.allocated` — выделенные блоки, `.logical` — логическая длина |
| `ScanProgress` | Число обработанных объектов, уже найденные блоки и текущий путь |
| `FileIdentity` | Пара устройства и inode; отделяет одинаковые пути от одинаковых объектов |

Плоский словарь позволяет выбирать узел по пути без рекурсивного копирования деревьев. `children(of:metric:ascending:)` сортирует детей по размеру; при равенстве используется путь. `ancestors(of:)` восстанавливает цепочку от корня. Агрегирование размеров использует насыщающее сложение с верхней границей `Int64.max`.

Узел-каталог содержит сумму детей, без блоков самого каталога. `descendantCount` не включает сам узел. Повторные имена файла сохраняют логический размер, но получают нулевой выделенный размер и `sharesStorage`. Повторный каталог получает `accountedAtID` и не обходится снова. ID стабилен лишь в пределах пути, а `FileIdentity` нужен для проверки замены объекта.

`scanIssueCount` хранит полное число ошибок в поддереве, включая ошибки объектов, метаданные которых не удалось прочитать. Это позволяет точно уменьшать общий счётчик после переноса папки, даже если сохранены описания только первых 200 ошибок. `ScanSnapshot.removingSubtree(id:)` возвращает новый снимок с вычтенными размерами без сканирования; алгоритм описан в [snapshot-updates.md](snapshot-updates.md).

`topLevelSelection` нормализует множественный выбор, исключая потомка выбранного родителя. `removingSubtrees(ids:)` применяет пакетное вычитание одним преобразованием. `trashSnapshot(parts:)` объединяет снимки системных корзин под виртуальным корнем; `displayName` задаёт понятные названия томам без изменения ID файловых путей. `TrashLocation`, `TrashManaging` и `TrashEmptyResult` описаны в [trash-workspace.md](trash-workspace.md).

`LocalTimeMachineSnapshot` — отдельный тип для даты группы локальных снимков, без файлового дерева и размеров. `TimeMachineManaging`, проверка дат, системные команды и авторизация описаны в [time-machine.md](time-machine.md).

## Ограничения и проверка

Снимок хранит все обнаруженные узлы в памяти: пространственная сложность O(N). Снимок не является журналом изменений; он не сериализуется и не содержит содержимое файлов. Инвариант конструктора `ScanSnapshot`: корень должен присутствовать в словаре.

`Tests/MacSpaceCoreTests/DiskScannerTests.swift` проверяет суммы, связи родителей, сортировку, подсчёт объектов, скрытые файлы, пакеты, ссылки и пустые объекты. Запуск: `./scripts/swift-local.sh test`.
