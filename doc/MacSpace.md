# Модуль MacSpace: интерфейс и состояние

## Эксплуатация

Запуск: `open .build/MacSpace.app`; сборка: `./scripts/build-app.sh`. `--scan /путь` выбирает начальную область. `⌘O` — выбор папки, `⌘R` — обновление активной вкладки, `⌘.` — отмена, `⌘↑`/`⌘↓` — навигация, `⌘⌫` — запрос переноса. Полное руководство: [usage.md](usage.md).

## Файлы

| Файл | Назначение |
| --- | --- |
| MacSpaceApp.swift | Окно, меню и команды |
| AppModel.swift | Состояние вкладок, кэши строк, мультивыбор, сканирование и файловые действия |
| CachedMapScene.swift | Фоновое построение и хранение геометрии всех отображаемых уровней |
| ContentView.swift | Вкладки, заголовок, выбор представления, панель выделения и подтверждения |
| SidebarView.swift | Разделы, область и кэшированные крупные папки |
| InspectorView.swift | Одиночные/суммарные сведения, действия и отчёт о пропусках |
| FolderContentsView.swift | Шкалы с разворачиванием и нативная таблица с Set ID |
| TreemapView.swift | Кэшированные блоки, шапки и раскрытие кликом |
| TimeMachineModel.swift | Список локальных снимков, мультивыбор, подтверждение и результаты удаления |
| TimeMachineView.swift | Таблица снимков, ошибки, авторизация и пустое состояние |

AppModel — MainActor ObservableObject. Сканирование, перенос и очистка выполняются actor из MacSpaceCore. UUID поколения отбрасывает опоздавший прогресс и результат отменённого сканирования. Отказ в доступе даёт частичный снимок, а не модальный сбой.

WorkspaceState хранит отдельно снимок, его версию, текущую папку, выбор, раскрытие и фильтр для вкладок анализа и Корзины. Переключение во время сканирования отменяет его; на время файловой операции вкладки заблокированы. Корзина читается при первом открытии и после пометки об устаревании новым переносом.

Третья вкладка Time Machine использует отдельную наблюдаемую модель, не подменяя сохранённые файловые области. Её изменения передаются AppModel через Combine; системные процессы выполняются вне MainActor. Удаление снимков блокирует переходы; `⌘R` читает только их список. См. [time-machine.md](time-machine.md).

selectedIDs — множественный выбор. select обрабатывает Command и Shift, SelectionSummary исключает вложенные выбранные элементы через topLevelSelection. Сведения не суммируют папку и её потомков повторно. Одиночный selectedID оставлен для фокуса и команд навигации.

Раскрытие шкал хранится в expandedFolderIDs. Оно не читает диск; исчезнувшие и опустевшие пути убираются после обновления. Карта хранит отдельное раскрытие, фоновые сцены и ключи версий. Подробности: [visualization.md](visualization.md), [performance.md](performance.md).

Перенос обрабатывает уникальные выбранные файлы/папки, собирает успехи и ошибки и одним removingSubtrees обновляет снимок. Очистка Корзины требует отдельного подтверждения и применяет только успешные ID. Если эти пути присутствуют в сохранённом анализе, его данные также уменьшаются без сканирования. Текущая папка сохраняется или заменяется ближайшим оставшимся предком.

## Проверка

AppModelTests проверяет навигацию, ошибки и отмену. FolderExpansionTests — строки дерева. TrashUpdateTests — перенос без сканирования. WorkspaceFeatureTests — мультивыбор файлов/папок, частичный отказ, вкладку Корзины, отмену подтверждения, очистку тестовых данных и кэши. TimeMachineModelTests — состояния и подтверждение снимков через подменённую службу. RenderingTests отрисовывает оба оформления, раскрытую карту, длинные заголовки, вкладки тестовой Корзины и Time Machine.
