# Модуль сканирования

## Эксплуатация

Пользователь выбирает папку через `⌘O`, дожидается результата или останавливает операцию кнопкой/`⌘.`. Обновление — `⌘R`. При отказе в доступе папка пропускается, а обход доступных соседей продолжается без модального диалога ошибки. Причины доступны через жёлтую полосу результата.

Программный интерфейс: `DiskScanner` — actor с методом `scan(root:progress:) async throws -> ScanSnapshot`. Прогресс передаётся через `@Sendable`-замыкание. Для отмены нужно отменить вызывающий `Task`. Политикой замены старого результата управляет `AppModel`.

## Алгоритм

1. Нормализовать выбранный корень и разрешить ссылки в его пути.
2. Выполнить итеративный DFS со стеком событий `visit` / `finishDirectory`.
3. Читать метаданные каждого объекта через `lstat`, не открывая содержимое файлов. Символические ссылки, FIFO и другие специальные объекты не обходить.
4. Для каталогов получить детей через `contentsOfDirectory`, включая скрытые файлы и пакеты. Восстановить URL детей относительно текущего пути: Foundation может вернуть эквивалентный путь с иным префиксом `/private`.
5. Запоминать `(device, inode)` файлов и успешно прочитанных каталогов. Повторно выделенные блоки файлов не учитывать; повторные каталоги не обходить, что также исключает циклы через повторные каталоги. Недоступный путь не блокирует последующий обход доступного пути к тому же каталогу.
6. На событии `finishDirectory` суммировать размеры и число потомков снизу вверх.
7. Считать ёмкость и свободное место тома, вернуть снимок.

Работа выполняется на executor actor, вне главного потока. Каждые 256 успешно прочитанных объектов выполняется `Task.yield()`. Проверка отмены происходит на каждом шаге. Прогресс ограничен примерно десятью сообщениями в секунду, плюс финальное сообщение. Полного числа объектов заранее нет, поэтому процент завершения не показывается.

Порядок обхода определяется лексикографическим порядком путей. Отказы в доступе распознаются по `EACCES`, `EPERM`, Cocoa `NSFileReadNoPermissionError` и вложенной POSIX-причине. Они не завершают анализ: содержимое папки не обходится, причина отмечается в отчёте и в узле. Если доступа нет к самому выбранному корню, возвращается частичный снимок с пометкой о пропуске; это относится и к отказу `lstat`, и к отказу перечисления детей. Интерфейс показывает «Папка пропущена», без модального диалога ошибки. После предоставления доступа достаточно повторить анализ.

Другие ошибки корня, например отсутствие пути, завершают анализ исключением; ошибки дочерних объектов увеличивают счётчик и оставляют остальные данные доступными. Для ограничения памяти сохраняются только первые 200 описаний ошибок.

Каждый каталог также накапливает `scanIssueCount`: собственную ошибку, ошибки чтения метаданных детей и суммы ошибок вложенных каталогов. Счётчик не ограничен списком из 200 описаний и используется для вычитания ошибок при последующем переносе поддерева в Корзину без повторного сканирования.

## Ограничения и проверка

Нет атомарного снимка файловой системы: файл может измениться или исчезнуть в процессе. Отмена кооперативная и не прерывает уже начатый системный вызов. Глубина дерева не расходует стек вызовов, но все узлы и таблицы идентичности находятся в памяти. Время зависит от числа объектов и задержек файловой системы; содержимое файлов для анализа не читается.

Тесты `DiskScannerTests` используют временные деревья и проверяют: рекурсивные суммы, Unicode, скрытые файлы, пакеты `.app`, ссылки наружу и циклы ссылок, жёсткие ссылки, разреженные файлы, FIFO, пустые файлы, продолжение обхода после двух недоступных папок, отказы доступа к метаданным и содержимому корня, распознавание Cocoa/POSIX-ошибок, восстановление после выдачи доступа, ошибочные корни и отмену. Запуск: `./scripts/swift-local.sh test`.
