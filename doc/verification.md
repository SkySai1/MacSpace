# Результаты проверки от 29 октября 2026 года

Среда: Apple Silicon arm64, macOS 26.6.2, Xcode 27.1, Swift 6.4. Минимальная целевая версия приложения — macOS 14; отдельный запуск на macOS 14 и Intel не выполнялся.

| Проверка | Результат |
| --- | --- |
| `./scripts/swift-local.sh test` | 54 теста в двенадцати наборах: файловый анализ, мультивыбор, Корзина, кэши и локальные снимки Time Machine |
| `./scripts/build-app.sh` | Release-приложение `.build/MacSpace.app` собрано для arm64 |
| Проверка локальной подписи | `codesign --verify --deep --strict` прошла |
| `Info.plist` | `plutil -lint` прошёл |
| Запуск через `open … --args --scan …/Sources` | Запуск успешен; отсутствие немедленного завершения подтверждено проверкой процесса |
| Отрисовка | Начальный экран и три представления в двух оформлениях отрисованы в тестовом `NSHostingView`; PNG в `.build/previews/` при включённом захвате |
| Системная Корзина | Перенос специально созданного UUID-каталога и восстановление с проверкой содержимого прошли; тестовые данные удалены |
| Отказ в доступе | Две закрытые папки пропущены, доступные соседи до и после них и вложенные файлы подсчитаны. Отказ чтения корня и его метаданных не останавливает анализ и не вызывает модальную ошибку. После возврата прав пересканирование успешно |
| Обновление после переноса | Размеры и счётчики вычитаются без сканирования; новые и изменённые после сканирования файлы не перечитываются. Проверены жёсткие ссылки, ограниченный отчёт об ошибках, сохранение контекста и неизменность снимка при неуспешном переносе |
| Разворачивание строк | Стрелка раскрывает детей без смены текущей папки; проверены несколько уровней, сортировка внутри родителей, фильтр, сворачивание и очистка удалённых путей. Развёрнутый список отрисован в светлом и тёмном оформлении |
| Новая карта | Размер справа в шапке при длинном имени; раскрытие/сворачивание не меняют координаты и счётчик построений. Первый выбор проверен вместе с настоящей компоновкой панели выбора |
| Производительность модели | 1000 смен выделения с чтением кэшированных строк заняли около 7 мс суммарно в одном проходе; повторных сортировок нет. Это не измерение полного отображения кадра |
| Очистка Корзины | Проверена только на UUID-каталогах теста: подтверждение и отмена, сохранение корня, защита постороннего/подменённого пути и цели ссылки, отказ доступа и обновление обоих снимков. Пользовательская Корзина не очищалась |
| Time Machine | Реальное чтение `tmutil listlocalsnapshotdates` успешно, локальные снимки в среде отсутствуют. Удаление проверено через подменённый исполнитель: даты, точный набор команд, повторная проверка списка, частичный отказ, отмена авторизации, тайм-аут и отмена процесса. Настоящие снимки не удалялись |
| Интерфейс Time Machine | Таблица в двух оформлениях, мультивыбор, отказ доступа и пустое состояние отрисованы через тестовую службу; высота окна остаётся в заданных пределах |

Автотесты проверяют ограничения пути и подтверждение через модель состояния. Отдельная проверка Корзины вызывает системный API `FileManager.trashItem`, который используется приложением. Безвредный вызов AppleScript `/usr/bin/true` прошёл вне sandbox; команды удаления Time Machine и запрос администратора в тестах подменены. Полный сценарий нажатия кнопок системного диалога, TCC-разрешения, реальное удаление снимков, сетевые/внешние тома и notarization в этой среде не проверялись. Матрица ручных проверок: [development.md](development.md).
