# MacSpace

Нативное приложение для анализа дискового пространства на macOS 14 и новее. SwiftUI, Swift 6, без внешних зависимостей.

- Шкалы размеров с долей каждого объекта в текущей папке и разворачиванием вложенных строк по стрелке.
- Карта с размером справа в шапке, раскрытием по клику и готовой геометрией в ОЗУ.
- Таблица содержимого: сортировка по размеру, имени и типу; фильтр по имени.
- Навигация по папкам, сведения об объекте и переход в Finder.
- Мультивыбор файлов и папок, пакетный перенос в Корзину с вычитанием размеров без повторного сканирования.
- Отдельная вкладка анализа доступной системной Корзины и очистка после подтверждения.
- Вкладка локальных снимков Time Machine: даты, мультивыбор и удаление после подтверждения с системной авторизацией.
- Кэширование строк, форматирования и раскладок карты для быстрого выбора объектов.
- Фоновое сканирование, отмена, скрытые файлы и пропуск недоступных папок с продолжением анализа.

## Сборка и запуск

Нужны macOS и Xcode с компилятором Swift 6 или новее. Откройте `Package.swift` в Xcode или выполните:

```sh
./scripts/build-app.sh
open .build/MacSpace.app
```

Скрипт создаёт `.build/MacSpace.app` для архитектуры текущего Mac, включая иконку и локальную ad-hoc подпись. Для отладочной сборки: `./scripts/build-app.sh debug`. Публикация и notarization не настроены.

Для запуска сразу с выбранной папкой:

```sh
open .build/MacSpace.app --args --scan "$HOME/Downloads"
```

## Проверка

```sh
swift test
# В среде с ограничением записи в пользовательские кэши:
./scripts/swift-local.sh test
```

Тесты создают собственные временные каталоги. Сканирование проверяется на настоящих файлах, ссылках, разреженных файлах и ошибках доступа; пользовательские данные не изменяются.
Проверка отрисовки требует графическую сессию macOS. Снимки для просмотра: `MACSPACE_CAPTURE_PREVIEWS=1 ./scripts/swift-local.sh test --filter RenderingTests` → `.build/previews/`.
