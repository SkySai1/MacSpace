# Инструкции для разработки

- MacSpace — нативное приложение macOS на SwiftUI. Используйте Swift 6, системные API и Swift Package Manager; не добавляйте зависимости без необходимости.
- Разделяйте сканирование и расчёты (`MacSpaceCore`) и интерфейс (`MacSpace`). Файловые операции не должны блокировать главный поток.
- Не переходите по символическим ссылкам при обходе. Файлы и папки переносите в Корзину после подтверждения с повторной проверкой пути. Постоянное удаление разрешено явной командой очистки Корзины после проверки её системных корней либо командой удаления выбранных локальных снимков Time Machine после проверки дат; требуется подтверждение. Корзину тестируйте на собственных временных данных, удаление снимков — через подменённую службу без изменения настоящих резервных копий.
- Для каждого модуля поддерживайте отдельный файл `./doc/<module>.md`: руководство по эксплуатации, назначение, техническое описание, ограничения и проверка. Обновляйте документацию вместе с кодом.
- Пользовательские надписи и документация — на русском языке. Поддерживайте клавиатурную навигацию и системные настройки оформления.
- Перед завершением запускайте `swift test` и `./scripts/build-app.sh`. Изменения алгоритмов и файловых операций проверяйте содержательными тестами на временных каталогах; не трогайте пользовательские данные в тестах.
